# MonoVoice Apps

Платформа каталогу та панель адміністрування для розповсюдження незалежних програмних додатків та утиліт MonoVoice.

Платформа побудована на базі React 19, TypeScript, Tailwind CSS, Vite, Express та Cloud Firestore із дворівневою моделлю захисту критичних дій (Scrypt хешування, Sudo-токени, Action Password, захист від підбору паролів та криптографічне підтвердження).

---

## 🛠️ Системні вимоги

- **Node.js**: версія 18 або вище (LTS рекомендовано)
- **npm**: версія 9 або вище

---

## 🚀 Швидкий старт для локальної розробки

1. **Клонуйте репозиторій:**
   ```bash
   git clone <URL_ВАШОГО_ПРИВАТНОГО_РЕПОЗИТОРІЮ>
   cd website
   ```

2. **Встановіть залежності:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Створіть файл змінних середовища:**
   Створіть файл `.env` на основі наданого шаблону `.env.example`:
   ```bash
   cp .env.example .env
   ```
   *Налаштуйте власні безпечні значення паролів та секретів у локальному файлі `.env`.*

4. **Запустіть сервер у режимі розробки:**
   ```bash
   npm run dev
   ```
   Додаток буде доступний за адресою: [http://localhost:3000](http://localhost:3000)

## 🔐 Змінні середовища

Усі змінні середовища налаштовуються у файлі `.env` (для локального середовища) або в Secret Manager хостингу (для Production):

| Змінна | Обов'язкова у Prod | Опис |
|---|---|---|
| `PORT` | Ні | Порт HTTP-сервера (за замовчуванням: `3000`). |
| `NODE_ENV` | Так | Режим оточення (`development` / `production`). |
| `APP_URL` | Ні | Базовий URL сайту для формування QR-кодів і посилань (напр. `http://localhost:3000`). |
| `ADMIN_USERNAME` | Ні | Логін адміністратора (за замовчуванням `admin`). |
| `ADMIN_PASSWORD` | Так | Пароль для входу в адмін-панель та операцій Sudo (мінімум 12 символів). |
| `ADMIN_ACTION_PASSWORD` | Так | Окремий пароль для створення/зміни програм і бекапів (мінімум 12 символів, відмінний від `ADMIN_PASSWORD`). |
| `COOKIE_SECRET` | Так | Ключ для криптографічного підпису cookie-сесій (мінімум 16 символів). |
| `AUTH_SALT` | Так | Сіль для алгоритму хешування паролів Scrypt (мінімум 16 символів). |
| `GEMINI_API_KEY` | Ні | API-ключ Gemini (за потреби генерації контенту). |

## 📁 Структура проєкту

- `src/` — клієнтський та серверний вихідний код
  - `src/components/` — UI-компоненти інтерфейсу та адмін-панелі
  - `src/pages/` — сторінки каталогу, деталей та входу
  - `src/server/` — Express API, маршрути адміністрування, сервіси автентифікації та бекапів
  - `src/data/` — початкові статичні дані програмного каталогу
- `server.ts` — точка входу Node.js/Express сервера
- `tests/` — автоматизовані тести безпеки, протоколів та підключень
- `storage/` — локальні дані, логи та бекапи (*ігноруються в Git*)
